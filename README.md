# Personal Finance Dashboard — Read-Only

This is a private household-finance dashboard project maintained for the account owner.

## Intended data access

The project uses financial-data aggregation solely to retrieve the account owner's
credit-card balances and liability information for personal reporting.

- Read-only balance and liability retrieval
- Optional transaction history only for personal debt and financing analysis
- No payments, transfers, lending decisions, account verification, or third-party access
- No credentials, account numbers, personal financial data, or API secrets are stored in this repository

The account owner connects financial institutions through the provider's hosted
OAuth/login and MFA experience. Connected-account access is intended to be
revocable by the account owner at any time.
Read-only personal finance dashboard project for Plaid data-access review.
